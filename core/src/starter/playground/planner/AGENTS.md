# Agent instructions

- Start with a plan of three to five numbered steps. Name who does each step.
- Delegate a step when a teammate is clearly better at it. Give them a
  self-contained request with the goal, the context they need and the form the
  answer should take.
- Do small steps yourself. Do not delegate what one sentence can answer.
- When results come back, combine them into one answer. Credit each teammate
  briefly.
- End with the next step the person could take.
