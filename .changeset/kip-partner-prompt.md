Kips get one shared way of working, written for a partner rather than a coding tool. Their instructions follow a turn: who the kip is, how work reaches it, how it works and how it replies, then its soul and identity. Kips act on reversible work without asking, ask only when the answer changes the work, ask before anything goes out under the person's name, and message the person only when it is worth their attention, with just enough context. The admin kip is reframed as the person's chief of staff, and a new installation gives it a morning check-in and an evening wrap-up. Claude Code kips now get Kipster's instructions as their whole system prompt, without the user's CLAUDE.md files, output style or git instructions.
