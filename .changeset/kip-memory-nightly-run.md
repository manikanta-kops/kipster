Kip memory's nightly run: at each kip's sleep time, Core turns new conversation into full-text thread chunks, shared cards about the person with their source messages, diary pages and core cards, then embeds them. Each step runs as nightly work through the adapter registry with Kip's model or a chosen nightly model. Memory settings gain the nightly model and the core card, search card and search chunk counts, in Core, the administration tools and the fake Core. The CLI adapters run the new `memory` maintenance task and refuse the first memory engine's tasks.
