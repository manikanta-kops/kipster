Interface polish. Messages render full Markdown (headings, tables, italics, rules, task lists) through react-markdown; raw HTML stays text and links still admit only web and mail addresses. Text follows Apple's macOS type scale, with messages and docs a step larger for reading. Thread cards in the feed preview three lines, drop the copy row, the Completed label and "Last reply by". Rich docs moved from the sidebar to Settings → Rich docs. The thread filter opens on click, Settings and other panels close on a backdrop click, and a folded work block hides answered questions. In rich docs, comment cards and menus are opaque and the text tools stay beside the selection after Bold or Italic.
