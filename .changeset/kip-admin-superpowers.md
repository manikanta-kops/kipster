Kip can change everything a person can change in the app: workspaces, kips and their identity files, groups, execution settings, learning, appearance, desktop notifications and updates. It uses two tools backed by one administration catalog in Core, and reads a `kipster-admin` skill file for how-to guidance. Core now supplies every execution's tool definitions, so adapters no longer define their own. Palette, theme and desktop notification choices are kept in Core and apply live in every window.
