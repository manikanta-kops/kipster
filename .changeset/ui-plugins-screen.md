Add a Plugins screen. When Core reports Kipster Plugins ready, the sidebar and Settings show Plugins: a searchable catalogue grouped by category that shows which plugins are available, why others are not, and how many accounts are connected. A plugin's page connects an account, asking for the service's address first when it needs one, then opens the service's sign-in in a new tab and follows it until it finishes. Connected accounts can be added, renamed, made the default, reconnected and disconnected. Sign-in problems, such as a service that only connects from the computer running Kipster or a window reaching Core over plain HTTP from another computer, are explained in plain words. The demo Core serves a sample plugin catalogue.
