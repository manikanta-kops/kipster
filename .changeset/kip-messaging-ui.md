Kips messaging each other is visible in the app. A thread another kip started shows its sender, a Kip message tag and the thread it came from; sent messages show as cards and answers say which thread they came from. Threads waiting for a kip say so in the feed, the thread, the sidebar and the status island, and every link opens the other thread. A filter next to the theme toggle shows all threads, the ones you started or the ones from other kips.
